📁 경로 설정
cookies.txt 파일을 선택하거나 여기에 드래그하세요

쿠키 파일 만드는 법:

  1. Chrome 확장 Get cookies.txt LOCALLY 설치
  2. canvas.ssu.ac.kr 로그인 상태에서 확장 아이콘 클릭
  3. Export 클릭 → 다운받은 파일을 위 버튼으로 업로드
